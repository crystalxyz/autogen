# HumanEvalPlus Benchmark

This scenario runs [HumanEvalPlus](https://github.com/evalplus/evalplus), the
augmented HumanEval benchmark from EvalPlus that adds ~80x more stress-test
inputs per problem to expose subtle bugs that the original HumanEval tests
miss.

The agent setup is identical to `HumanEval/Templates/AgentChat`: a
`MagenticOneCoderAgent` proposes a solution and a `CustomCodeExecutorAgent`
runs the wrapped `check(candidate)` test, with the team allowed to cycle
back if the tests fail.

## Running the tasks

```bash
cd benchmarks/HumanEvalPlus
```

Update `config.yaml` to point to your model. Then download and expand:

```bash
pip install evalplus            # canonical data source (recommended)
python Scripts/init_tasks.py
```

If `evalplus` is not installed the script falls back to the HuggingFace
`evalplus/humanevalplus` dataset.

The init script uses each problem's canonical solution as an oracle to
compute expected outputs over the union of `base_input + plus_input`, and
materializes a `check(candidate)` function that asserts equality on every
case (with `math.isclose` tolerance for problems that declare a non-zero
`atol`).

Run with:

```bash
agbench run Tasks/humaneval_plus_AgentChat.jsonl
agbench tabulate Results/humaneval_plus_AgentChat
```
