# MBPP+ Benchmark

This scenario runs [MBPP+](https://github.com/evalplus/evalplus), the
EvalPlus-augmented MBPP benchmark, on the same `MagenticOneCoderAgent` +
`CustomCodeExecutorAgent` round-robin loop used by `HumanEval/AgentChat`.

## Running the tasks

```bash
cd benchmarks/MBPPPlus
pip install evalplus
python Scripts/init_tasks.py
agbench run Tasks/mbpp_plus_AgentChat.jsonl
agbench tabulate Results/mbpp_plus_AgentChat
```

The init script uses each problem's canonical solution as an oracle to
compute expected outputs over `base_input + plus_input`, and synthesizes a
`check(candidate)` function (with `math.isclose` tolerance for problems
declaring a non-zero `atol`).
